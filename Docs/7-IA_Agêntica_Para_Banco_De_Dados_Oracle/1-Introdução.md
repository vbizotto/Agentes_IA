# Introdução

## Considerações iniciais

### Visão geral

Bem-vindo(a) a este módulo sobre IA agêntica e Oracle Database. Vamos explorar a busca vetorial, o ciclo de vida e o ambiente de execução de agentes, além de conhecer ferramentas para criar agentes corporativos e integrá-los ao banco de dados.

Ao longo do módulo, veremos como representar e pesquisar dados por significado, como criar fluxos de trabalho com agentes e como os recursos de segurança do banco de dados se aplicam às integrações.

### Objetivos de aprendizagem

Ao concluir este módulo, você será capaz de:

- Explicar a função do ciclo de vida e do ambiente de execução de agentes.
- Descrever como embeddings e vetores permitem buscas semânticas no Oracle Database.
- Identificar as etapas de um fluxo de busca vetorial, da geração de embeddings às consultas por similaridade.
- Reconhecer os recursos do Oracle AI Database Private Agent Factory para criar e implantar agentes.
- Entender como o servidor MCP do Oracle Autonomous AI Database utiliza a autenticação e os controles de acesso do banco.

### Benefícios para você

Este módulo conecta os conceitos de agentes a recursos de dados e execução da Oracle. Você verá como combinar busca semântica e SQL, explorar agentes corporativos e compreender os controles que ajudam a proteger essas integrações.

# Conteúdo do módulo

## 1. Ciclo de vida e ambiente de execução de agentes

Vamos começar examinando o que é necessário para levar a lógica de um agente à produção, incluindo os componentes de tempo de execução que a envolvem.

## 2. Introdução à Busca Vetorial do Oracle AI

Em seguida, conheceremos embeddings e vetores e veremos como a busca por similaridade pode encontrar informações pelo significado, além da correspondência exata de palavras.

## 3. Fluxo de trabalho da Busca Vetorial

Percorreremos as etapas para gerar embeddings, dividir documentos em partes, armazenar e indexar vetores e realizar consultas combinadas com SQL.

## 4. Demonstração da Busca Vetorial do Oracle AI

Acompanharemos exemplos de busca semântica e veremos como aplicar filtros relacionais às consultas vetoriais.

## 5. Oracle AI Database Private Agent Factory

Conheceremos os agentes pré-configurados e o construtor visual do Private Agent Factory, além de suas integrações e opções de implantação.

## 6. Demonstração do Private Agent Factory

Exploraremos o Agente de Conhecimento e o Agente de Análise de Dados e criaremos um fluxo simples com o Construtor de Agentes.

## 7. Servidor MCP do Oracle Autonomous AI Database

Por fim, veremos como o servidor MCP se apoia nas credenciais, permissões e políticas de segurança do banco de dados.

Vamos começar!
